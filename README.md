# 👔 Smart Closet Stylist (스마트 옷장 & 코디)

스마트폰 전용 맞춤형 의류 코디 및 옷장 관리 앱입니다. 순수하게 '개인이 소장한 옷'을 기반으로 최적의 상·하의 및 소품 조합을 룰 기반 엔진으로 추천하며, 스마트폰 전면 카메라를 통한 실시간 거울 모드를 제공합니다.

---

## ✨ 핵심 기능

1. **9:16 스마트폰 단일 뷰 최적화 (모바일 웹 & Capacitor Android)**
   - 스크롤 락 및 터치 스와이프 제스처 지원
   - 세련된 다크 테마 & 글래스모피즘 인터페이스
2. **실시간 거울 카메라 모드**
   - 전면 카메라 WebRTC 스트림으로 실시간 착용 핏과 아이템 조합을 직접 대조
3. **양방향 룰 기반 매칭 엔진**
   - 상의 고정 ↔ 하의 고정 원터치 토글 (📌 핀 모드)
   - 색상 매트릭스 (네이비/화이트/베이지/블랙/카키 등 호환성 및 충돌 감점)
   - 소재 밸런스 (린넨+린넨 가산점, 린넨+울 계절 충돌 감점 등)
4. **스타일 조화도 & 갭(Gap) 보충 위젯**
   - 100점 만점 조화도 점수 및 뱃지
   - 소장 신발/벨트 가죽 톤 일치 룰 (브라운/블랙 톤 매칭)
   - 조화도 70점 미만 또는 필수 소품 부재 시 무신사 스탠다드 검색 링크 자동 연동
5. **소장 옷장 관리 (오프라인 지원)**
   - LocalStorage 영속화 및 사진 촬영/이미지 업로드 기반 아이템 등록/삭제
6. **GitHub Actions CI/CD 자동 빌드 & QR 코드 배포**
   - `main` 브랜치 푸시 시 Android APK 자동 빌드
   - GitHub Releases에 스마트폰 스캔용 **QR 코드** 및 APK 파일 자동 발행

---

## 🚀 빠른 시작

### 로컬 웹 실행
```bash
npm run build
# 브라우저에서 index.html 바로 열기 가능
```

### Capacitor 동기화 및 안드로이드 스튜디오 실행
```bash
npm run cap:sync
npm run cap:open
```
